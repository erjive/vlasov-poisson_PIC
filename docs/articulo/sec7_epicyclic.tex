%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\EJ{To be written from the notes in docs/modelo\_reducido (sections II, III, V and VI, condensed to five or six pages). There the model is called ``the reduced model''; since these notes use that name for the model with fixed angular momentum (section~\ref{Sec:VPSphSym}), we propose to call it ``the epicyclic model''. To be decided by the authors. Section~\ref{SubSec:FarRuns} refers to this section for three statements: the self-gravity makes the cloud rotate about its own center, the single parameter of the model compares this rotation with the differential rotation and is proportional to $\mu^2$, and $A$ is approximately proportional to $M_{gas}\sigma_J^{1/2}$.}
