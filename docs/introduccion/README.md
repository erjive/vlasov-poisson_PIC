# Introducción al problema

`vlasov_intro.tex` — notas didácticas sobre phase mixing, amortiguamiento de
Landau y variables ángulo-acción en Vlasov–Poisson con simetría esférica,
para alguien con formación en física o matemáticas que se inicie en el tema.

Se compila con `latexmk -pdf vlasov_intro.tex` (solo paquetes de TeX Live
estándar). 17 páginas.

Los números que aparecen en el texto salen de las corridas del repositorio;
los cuadernos que los producen están en `paper_runs/notebooks/`.
